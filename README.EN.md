# WEB Card Fravelz

[English Version](./README.md)

![Screenshot](resources/screenshot.png)

Personal web profile card with background video, Chinese character animations, and social media links.

## Features

- **Background Video**: Looping playback with playback, mute, and opacity controls
- **Chinese Greeting**: Character animation using Hanzi Writer
- **Profile Card**: Avatar, name, and links to GitHub, YouTube, and Portfolio
- **Responsive Design**: Adapts to different screen sizes

## Project Structure

``` txt
├── index.html # Homepage
├── resources/ # Resources (avatar, video, logo, screenshot)
├── scripts/ # JavaScript (video controls, Chinese animation)
└── styles/ # CSS Styles
```

## Technologies

- HTML5
- CSS3
- JavaScript (ES Modules)
- Hanzi Writer - animation Chinese characters
